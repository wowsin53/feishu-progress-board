# GIRT 日报更新

- 标题：【GIRT 今日任务日报】。
- 发送时间：每天北京时间00:30，REPORT_SEND_TIME=00:30。
- 日报日期：发送日前一天。例如9月15日00:30发送9月14日日报。
- 考勤：按日报日期统计，仅显示已打卡人数；未打卡显示人数和姓名。当前虚拟打卡声明继续保留。
- 今日完成：实际完成日期等于日报日期的任务数；无实际完成日期不猜测。
- 累计完成、未完成、逾期、即将到期及组内任务统计：现有飞书当前快照。正文的数据截至包含实际年月日和时间。
- 缺截止日期：只显示负责人去重姓名，不列任务详情。重点/逾期/即将到期仍保留任务及负责人。
- 日志中的date仍是实际发送日，当天手动和自动发送共用一次额度，历史日志不清空。上一个发送日的测试不会占用下一发送日的自动额度。
- 切换配置时使用REPORT_START_AT指定下一次00:30，避免在部署当晚因为当前时间已晚于00:30而触发补发。此时间之后继续正常每日调度，服务重启可补发当日漏发的一次。
- 该修改仅涉及日报；首页RoboMaster标识、飞书审核流程和已停用的自动删除服务保持原状态。

实现：server/reports/generate.ts负责前一日日期和名单；service.ts保留发送日防重并检查跨日；scheduler.ts提供00:30默认值和启用起始保护。管理页同步GIRT及前一日预览文案。
